# Documentación sobre Neovim

Apuntes del editor Neovim, integrados en la biblioteca Astro en
`/documentos/neovim/`. `toc.yaml` selecciona y ordena los capítulos Markdown.
Los títulos y niveles se definen en el frontmatter de cada capítulo.
Los archivos que no figuran en el índice se conservan como borradores.
